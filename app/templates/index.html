Hardware Pinout & Wiring

HW-477 to ESP32

The A3144 Hall-effect module (HW-477) operates as a digital switch. When a magnet's South pole is brought within 5-10mm, the digital output pulls LOW.

HW-477 Sensor Pin ESP32 Connection Description / Function
VCC 3.3V 3.3V DC Power Input (matches ESP32 logic level)
GND GND Common Ground
DO (Digital Out) GPIO 27 Active-LOW digital signal (Interrupt with INPUT_PULLUP)
AO (Analog Out) Not Connected A3144 is a digital switch; AO is not used
Key Hardware Principles:
  • Digital Switch: The A3144 provides pure on/off magnetic event switching. It is not an analog flux sensor.
  • Cumulative Counting: The ESP32 maintains its own cumulative counter in RAM, preventing event loss even if an HTTP transmission fails.
  • Debounce Filtering: 50ms software debounce prevents multi-triggering from contact vibration or magnet oscillation.

REST API Endpoints Reference

FastAPI Specs
Method Endpoint Description Request / Response
POST /api/sensor-data Called by ESP32 to upload cumulative event telemetry Payload: {"device_id": str, "event_count": int, "magnet_detected": bool, "uptime_ms": int}
GET /api/latest Fetch the latest sensor reading and device online status Returns reading object + online boolean (30s threshold)
GET /api/stats Calculated KPIs: total events, events in last 60s, device status Returns summarized KPI payload for dashboard cards
GET /api/history Paginated historical records in descending chronological order Params: limit, offset, device_id
GET /api/chart-data Formatted time-series vectors for Chart.js rendering Params: limit (default 30)
GET /api/health Backend and PostgreSQL database connectivity check Returns {"status": "healthy", "database": "active"}
